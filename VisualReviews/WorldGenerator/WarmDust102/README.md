# №102–103 · Тёплая песчаная пыль

В каждой паре сверху исходная пыль, снизу пробная. Опора — освещённый игровой песок RockyB P07 v4; медиана выбранной области sRGB 215/165/112. Вариант подмешивает 40% цветности этой опоры в линейном RGB к цвету рассеяния высотного тумана и альбедо объёмного тумана и двенадцати локальных банков. Ограниченное альбедо объёмного тумана после нормализации также меняет яркость. Коэффициенты плотности сохранены, включая локальное ослабление №94 у мокрой соли на Outer. Источник света, ручная экспозиция −12,7 и фаза 7 с общие для каждой пары.

На Small дальняя дымка в просвете приобрела песочно-бурый оттенок, у бокового склона видны более тёплые пылевые слои. Среднее изменение RGB в выбранной области дальнего просвета +8,34 / −2,49 / −12,59 из 255, в коридоре локальных объёмов +5,81 / −2,98 / −11,33. Составляющие в последнем измерении наложены. Пара показывает дюны у Small 2635 м; отдельный ракурс раскрытия долины на 3680 м в эти три пары не входил.

У северного массива изменение слабее: красный канал передней стены +2,37, синий −3,52. Над мокрой солью дымка под опорами заметно теплее. В отражающей полосе, выбранной по игровым лучам, изменение RGB +5,44 / −1,08 / −6,16. В ясном горном небе среднее абсолютное изменение 0,68/255, на металле поезда 1,89/255, в небе над Small 4,13/255. Правились свойства пыли, глобальный грейд, материалы поверхности и зеркала не менялись. Атмосфера влияет на видимый цвет этих объектов. Карта отражений была подключена и в конце движения.

Один новый проезд Mammoth по Outer, 140,26 м при 10 м/с; контроль №94 — 140,22 м на том же маршруте с той же камерой и тем же ослаблением над солью. В видео сверху №94, снизу тёплый вариант, синхронизация по старту движения. p95 кадра 18,77 → 18,56 мс. GPU p95 нового проезда 22,71 мс; в контроле отдельное время GPU не записывалось. Прогоны единичные. Новых проходов рендеринга для цвета не добавлено.

Три пары и движение сняты в одной игровой загрузке. Первый сопоставимый тёплый кадр в 00:44:08 UTC, примерно через пять минут после передачи окна. В интервал вошло устранение двух конфликтов имён при сборке. Слот возвращён Layout в 00:45 UTC. Исходный и тёплый варианты сохранены для выбора Антона.
