# Промежуточная подошва останца №71
Сверху вниз на изображениях и в видео — широкая 1.4, средняя 1.4.3 и минимальная №63. Общие верхняя стена (32 833 вершины), цвета вершин, материал 1.4, свет 02, грунт и камера. Для третьего ряда использован сохранённый игровой прогон №63. [С борта](images/side.jpg) · [Освещённая подошва](images/foot.jpg) · [Теневая сторона](images/shade.jpg) · [Поворот](images/bend.jpg) · [На ходу](images/drive.jpg) · [Синхронный проезд](drive.mp4).

Ширина внешней границы основания по X 666,77 / 499,28 / 292,08 м, по Y 600,69 / 412,03 / 231,25 м. Это размеры нижнего погребённого контура. На высоте 2 м над локальным нулём видимая ширина по X составляет 513,92 / 473,27 / 287,66 м, по Y 433,69 / 387,91 / 230,51 м. В средней версии шесть местных несимметричных выходов осыпей, между которыми открывается стена. 96 лучей измерили заглубление этой границы в игровой грунт от 1.96 до 6.07 м.

На повороте у среднего варианта видны раскрытая передняя стена и длинный правый сход. Широкий вариант занимает больше кадра по обеим сторонам. Вблизи средней подошвы часть вертикальных рёбер стены по-прежнему выражена. Начало задачи около 20:27 UTC, первая тройка составлена из штатных игровых состояний около 20:34, примерно 7 минут. Новая средняя форма и широкая контрольная сняты за одну игровую загрузку; минимальная взята из совпадающего по свету, камере, станции и маршруту прогона №63. Фотометрическое тождество между отдельными запусками не измерялось. Первый вызов сборки завершился до компиляции из-за блокировки временной папки; повтор с отдельной временной папкой прошёл.


Обычный Mammoth, 588 м. DX11 p95 кадра в порядке тройки 17.69 / 17.75 / 17.55 мс. Художественный выбор открыт. [Параметры](parameters.json).
