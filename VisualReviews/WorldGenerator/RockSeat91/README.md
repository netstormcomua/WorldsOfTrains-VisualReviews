# Выбранная посадка камней на основной карте 2.5
[Подход](images/approach.jpg) · [Кадр из поезда](images/moving.jpg) · [Камень крупнее](images/detail.jpg) · [Штатный проезд](drive.mp4).

У дороги Small сохранены 52 выбранные поправки по высоте из №67. Координаты каждого сохранённого объекта считаны непосредственно в игре. Наносы состоят из 16 224 треугольников и используют штатный песчаный материал.

На подходе за ближним бортом слева видны слоистый главный камень и низкие обломки. Нижняя часть главного камня скрыта песком, тень падает вправо. На втором кадре группу перекрывает поезд. Увеличенный фрагмент показывает масштаб этой детали в обычной игре.

Mammoth прошёл 135 м, p95 кадра 17.93 мс в DX11. Это проверка переноса выбранного варианта.
