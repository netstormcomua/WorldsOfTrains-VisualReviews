# Песок в движении · RockyB и MegaRipples

Семь пар для телефона. В каждой верхние два кадра показывают один участок песка крупно, нижние два — вид с поезда после 65 м движения по Small. Размер кадрирования внутри пар одинаков. Для двух основ по очереди меняется один параметр. База АТ — исходное смешивание двух проекций. АТ+ добавляет плавное пространственное смещение обеих проекций. Контраст 1,65× усиливает отклонение яркости фактуры от среднего; сила нормали прежняя.

Свет и выбранная игровая пыль DuneStorm 04 одинаковы. Сохранены 12 объёмов, фиксированная фаза для крупных планов, синхронное смещение при движении. Сцену открывает контроль 02. Масштаб RockyB откалиброван в проекте; для 12 исходный период основных гребешков 1,33 м, при тайле 18 м — 2 м.

DX11/SM5, 1440×810, лимит 60 fps, один проезд на вариант.
