# Облачные пятна у Mammoth · №57

В нативной текстуре оптической глубины Unreal есть пятна. На участке Small при переключении облачной тени линейное затемнение между 10-м и 90-м процентилями составило примерно 0,4–1,1% на четырёх фазах. Сокращение шага привязки теневой карты с 20 км до 50 м позволило проверить карту рядом с путём. [Штатная теневая карта и маршрут](images/native.jpg).

Второй стенд представляет **имитацию**. Видимый плоский полупрозрачный слой на высоте 330 м и проекция на главном источнике света читают одну текстуру, одну фазу и ветер (11,4; −3,8) м/с. В OFF облака продолжают двигаться. В ON выборка для поверхности смещена по лучу к солнцу с учётом её высоты. Штатный объём отключён в обоих вариантах этого стенда. Сохранён прежний игровой свет 2.3.

При фазе 7 с одно пятно пересекает путь и поезд. По проекции сверху ширина около 100 м, длина около 116 м при пороге 20% затемнения, оценка по масштабу у оси пути. Участки ближнего песка и освещённого металла между фазами 0/7 с изменили яркость в среднем на 62,5 и 50,9 уровня из 255. При повторении нулевой фазы расхождение 0,56 и 0,79. [Пятно сверху](images/mask.jpg) · [OFF/ON в одной фазе](images/switch.jpg) · [Три фазы](images/phase.jpg) · [Кадр в движении](images/ride.jpg) · [Синхронный проезд](drive.mp4).

При движении кромка последовательно проходит по песку и боку Mammoth. Снизу облака выглядят плоскими, некоторые пятна повторяют овальную форму. Это технический кандидат. Для фотореалистичной сцены вид облаков требует художественного решения.

DX11 1440×810, проезд 165.2/165.1 м, p95 кадра 17.83/18.24 мс, GPU 18.01/21.13 мс, по одному прогону OFF/ON. [Параметры и измерения](parameters.json).
