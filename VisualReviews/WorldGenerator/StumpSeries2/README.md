# Вторая серия испытаний песчаниковой горы
Слева в сравнениях исходное состояние каждого опыта, справа его изменение. База для формы и осыпи — сохранённое сочетание №95. У слоистости, тафони и потёков свои исходники из первой серии. На [фотографии NPS/Herbert](https://www.nps.gov/cany/learn/nature/chinle.htm) сопоставляли видимые пропорции стены и осыпи. Четыре сечения фотографии дали долю стены около 29–36% высоты массива в кадре.

| Опыт | Что видно | p95 кадра, исходный → опыт, мс |
|---|---|---:|
| II.1 · Пропорции стены | Правое плечо подходит выше к шапке. Укороченная стена различима на повороте и на однотонной оболочке. Широкая передняя часть осыпи остаётся гладкой. | 17.42 → 17.44 |
| II.2 · Перелом у подошвы | Под правой стеной появилась тонкая прерывающаяся грань. При приближении виден перегиб у основания, в тени переднего сектора он слабее. | 17.42 → 18.06 |
| II.3 · Выемка в стене | Середина передней стены уходит вглубь при сохранении шапки. Близко видно ребро выемки, на движущемся поезде разделение плоскостей слабое. | 17.42 → 17.57 |
| II.4 · Плечи разной высоты | С обратного направления одно плечо явно ниже, а на нём выступают прямолинейные концы старых блоков. Два основания на повороте уверенно не разделяются. | 17.42 → 17.66 |
| II.5 · Выход пласта | Изменилась форма контакта на среднем и ближнем плане. Непрерывное направление пласта между стеной и осыпью с поезда прочитать трудно. | 17.42 → 17.80 |
| II.6 · Крупность осыпи | Зерно открывается и исчезает пятнами на склоне. На среднем плане разделение потоков по крупности слабое. | 17.42 → 17.66 |
| II.7 · Выклинивание слоёв | Часть тёмных полос стала прерывистой и спокойнее. В центральной части крупного плана несколько параллельных дуг ещё повторяются. | 17.57 → 17.70 |
| II.8 · Маска старых блоков | Вертикальные полосы на скошенных боках старых блоков исчезли в близком сравнении. На соседнем склоне мелкое зерно сохранилось. | 17.42 → 17.87 |
| II.9 · Группы тафони | Сплошная россыпь ячеек сменилась небольшими группами и гладкими промежутками. На отдельных группах остались вытянутые тёмные штрихи. | 17.99 → 17.55 |
| II.10 · Начало потёков | Сплошное затемнение стены ослабло. Отдельные потёки с точкой начала у уступа на игровом повороте слишком слабы. | 17.46 → 17.49 |

Для демонстрации сохранено сочетание II.1 + II.2 + II.8. На дополнительной копии к нему добавили только полку II.5. При том же свете на обратном профиле появляется отчётливый короткий выступ с острым концом; в лоб на среднем плане длинная полка теряется в стене. В качестве основной кандидатуры серии оставлено сочетание без полки. Обе копии сохранены для сравнения. p95 кадра 17,61/17,46 мс, по одному проезду. На природном референсе склон делится на широкие рёбра и глубокие промежутки до самой подошвы. В игровых вариантах этого пока нет. Художественная приёмка открыта. Первое сравнение формы снято в 01:28 UTC, через 61 мин 46 с после первого сохранённого расчёта серии, включая работу над бровкой Small. Переключение первых четырнадцати состояний прошло без полной перезагрузки карты. Для двух сочетаний потребовалось ещё по одной игровой загрузке.

Один проезд длиной 240 м на вариант. Все четыре исходника и десять опытов сняты в одной игровой загрузке, с одинаковой сценой и светом. [Параметры, треугольники и GPU](parameters.json).
