# Одиночный большой останец · Stump01

Первый вариант по [эскизу Антона №01](https://github.com/netstormcomua/WorldsOfTrains-VisualReviews/blob/1a5298270894a3109045cd36ea67bf4c8b88db8c/VisualReviews/WorldGenerator/MesaForms02/01-stump.jpg). Эскиз создан с помощью ИИ. В игре верхняя площадка, стена, расщелины и широкое подножие входят в одну сетку из 119232 треугольников. На стенах нет отдельных камней. Seed 84152.

[Контур эскиза и геометрии](images/contour.jpg) · [Форма и песчаник с одной камеры](images/form.jpg) · [Игровой вид вблизи](images/warm.jpg) · [Кадр из Mammoth](images/drive.jpg) · [Синхронный проезд](drive.mp4).

[Край в свете](images/shade.jpg) · [Обратная грань в тени](images/edge.jpg) · [Сравнение с RockyDesert Demo](images/demo.jpg). На оболочке материал использует альбедо поверхности утёса RockyDesert, нормаль исходного MI_Side_Rock_A1 и мелкую фактуру скана Cliff Side с шагом 1,8 м. Проекция выполняется в мировых метрах. Маски меняют цвет, шероховатость и выраженность пластов. В кадре Demo виден самостоятельный исходный экземпляр; диагностический экземпляр на стенд поставлен после завершения проездов. Его измеренная ширина по локальной X с масштабом стенда 16.04 м. [Источник скана Cliff Side, CC0](https://polyhaven.com/a/cliff_side).

Столовая вершина и цельная отвесная стена узнаваемы с поезда. На одинаковой видимой высоте ширина верхней стены на 20% вниз составляет 1,17 высоты у UE и 1,34 на эскизе. На 55% вниз — 1,21 и 1,50. Нижняя часть уже эскиза; большая доля осыпей выглядит как прямые лучи одинаковой длины. На свету песчаник тёплый, в тени цвет и мелкие пласты читаются слабее. Крупные вертикальные рёбра ещё слишком ровны. Это промежуточный вариант для отдельного опыта с формой осыпи.

На Outer при 1440×960, DX11, оба варианта переключены в одной загрузке. Однотонная форма: 587.6 м, кадр p95 17.82 мс, GPU 17.51 мс. Песчаник: 587.7 м, кадр p95 17.69 мс, GPU 17.43 мс. По одному проезду на материал, вывод о разнице стоимости ограничен. [Параметры и замеры](parameters.json). Вариант передан Антону для художественной оценки.
