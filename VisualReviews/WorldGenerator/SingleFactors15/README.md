# Одна гора · десять факторов

Контроль — SingleMountain 1.3.0, поверхность 1.1, seed 84152. Все состояния сняты в одной загрузке с одного и того же поезда на Outer, 1440×810, DirectX 11. Для каждого состояния близкая камера фиксирована, момент бокового кадра задаёт расстояние +210 м.

10. [Два уровня детализации в одном ракурсе](images/lod.jpg). Число треугольников по уровням: 57280, 22911, 7446. Автоматически выбранные уровни (близко / запад / восток): 0, 0, 0.

В совместном варианте прорезь изменила силуэт и дала читаемую тень на правом ребре. Из поезда легче различить осыпные конусы. У самой стены светлые серые выходы выделяются на тёплом песчанике, а вытянутые губы уступов и сглаженные края выемок по-прежнему выглядят искусственными. Фото показывает тонкую верхнюю кромку. В факторе 01 на одной размеченной вертикали в проекции верхний уступ занимает около 28% видимой высоты, на фотографии — около 11%. Эти числа характеризуют конкретный ракурс и выбранные границы. Один прогон каждого состояния даёт наблюдаемые времена кадра; небольшие различия порядка миллисекунды не позволяют ранжировать стоимость отдельных факторов.

При непрерывном отдалении фиксированной камеры от горы движок выбрал LOD0 на 644 м, LOD1 на 2913 м. Это диагностическое отдаление выполнено после обычных поездных замеров.
