# Подножие большого останца · проба 1.1

[Контроль 1.0](https://github.com/netstormcomua/WorldsOfTrains-VisualReviews/blob/d0d50e5cc55b7600eb89ab4c35907906d070dafd/VisualReviews/WorldGenerator/Stump01/README.md). Камеры, игровой свет, seed, сеточная топология и материал песчаника совпадают. Проверка координат подтвердила неизменность всех 32642 вершин начиная с 88 м. Пересчитаны 27253 вершин внизу. Оба варианта состоят из одной непрерывной сетки, без отдельных камней на стенах.

[Одна серая поверхность](images/gray.jpg) · [Та же форма в песчанике](images/warm.jpg) · [Близкий игровой вид](images/near.jpg) · [Кадр Mammoth](images/drive.jpg) · [Синхронный проезд, 1.0 сверху](drive.mp4).

Тринадцать конусов привязаны к локальным углублениям в стене. У каждого свои направление, длина, ширина и изгиб оси. При пересечении соседних конусов поверхность описывает общую осыпь. Часть вертикальных рёбер заканчивается над ней. Фактическая длина по рецепту от 71.4 до 143.0 м.

На сером виде исчез повтор одинаковых прямых лучей. Часть рёбер заканчивается у кромки стены. Передний конус поворачивает, соседний склон даёт отдельную тень; в боковом проезде Mammoth эта разница остаётся видна. На эскизе подножие шире и положе: в 1.1 граница левого конуса крутая, а правый склон выглядит сглаженным. Это сравнение подтверждает вклад формы; фактура в обеих версиях одна.

Обычный проезд по Outer, DX11, 1440×960: для песчаника 1.0 пройдено 587.7 м, кадр p95 17.69 мс; для 1.1 — 587.9 м и 17.96 мс. Одно наблюдение на вариант. Снимки 1.0 сохранены в предыдущем прогоне, 1.1 снят тем же драйвером на отдельной карте. Изменение фактуры и художественная приёмка в этот опыт не входят. [Параметры и замеры](parameters.json).
