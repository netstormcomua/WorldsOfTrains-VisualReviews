# Проверка одного освещённого ребра

Слева на [крупном фрагменте](images/edge.jpg) — контроль SingleMountain 1.3.0, поверхность 1.1. Справа — локальная проба на той же горе и в том же кадре. Изменён только участок правого выступа. Пять прерывистых полок дают собственную тень. Две свободные кромки получились почти прямыми, отчего отдельные полки выглядят приклеенными к гладкой стене. Это промежуточное наблюдение для общей геологической пробы.

[Сравнение с поезда](images/near.jpg) · [Штатная боковая камера](images/drive.jpg) · [Синхронное движение: сверху контроль, снизу проба](drive.mp4) · [Полный игровой кадр](images/new-near.jpg).

Seed 84152, свет и материал одинаковы. Все 2450 камней общие для обоих состояний. Геометрия меняется только в пределах одной грани на высоте 54–146 м. Прибавка составляет 190 треугольников. Проверены пределы изменения, старый контур вне участка и точный хеш результата. Оба обычных проезда DX11 — около 687 м; кадр p95 в пробе 17,78 мс, GPU 17,61 мс. [Измерения](parameters.json). Дальнейший опыт включает выемку в объёме и плавно выклинивающийся пласт.
