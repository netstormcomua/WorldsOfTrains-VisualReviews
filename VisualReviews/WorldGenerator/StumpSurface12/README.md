# Согласованная фактура песчаника · материал 1.2

Одна версия поверхности на [зафиксированном останце 1.1](https://github.com/netstormcomua/WorldsOfTrains-VisualReviews/blob/43259c217d93b2d69626565877ab18dbd1acec22/VisualReviews/WorldGenerator/StumpTalus11/README.md). Оба прохода работают с одним компонентом и одним ассетом из 119232 треугольников. Отличается только материал. Старый материал сохранён.

[Близкая стена на свету](images/sun.jpg) · [Близкая стена в тени](images/shade.jpg) · [Освещённый край](images/lit-edge.jpg) · [Общий вид](images/near.jpg) · [Кадр с Mammoth](images/drive.jpg) · [Синхронный проезд](drive.mp4).

На реальном экземпляре SM_RockSide_A24 в RockyDesert Demo проверены слот MI_Side_Rock_A1 и родитель M_Side_RockMaster. Обход соединений до Base Color подтвердил T_Cliff_Surface_alb, до Normal — T_Cliff_Surface_nm. Родной граф также смешивает песок и использует индивидуальные маску и нормаль меша. [Экземпляр в Demo и под светом стенда](images/specimen.jpg).

В пробе обе карты поверхности утёса считываются с одинаковым шагом 3,6 м. Для каждой из трёх проекций совпадают ориентация координат, сдвиги выборок и веса смешения. Нормаль переведена из системы соответствующей плоскости в мировую. Сохранён собственный тёплый оттенок, близость к Demo оценивается визуально. 3,6 м — выбранный шаг для оболочки останца. Точки близких кадров найдены трассировкой на фиксированной геометрии.

На освещённом участке видна мелкая неоднородность цвета и рельефа; у контрольного материала сильнее выражены горизонтальные слои. В тени новая поверхность чуть светлее, рисунок ещё различим. В проверенных крупных планах явной квадратной сетки повторов и длинных растянутых полос не видно. При этом зерно местами выглядит скорее как песок, а на общем поездном виде визуальная разница мала. Это ограничивает вывод о сходстве с природным песчаником.

DX11, 1440×960, один игровой запуск с переключением материала. Действующий материал: 587.7 м, кадр p95 17.66 мс, GPU 17.53 мс. Проба: 587.6 м, кадр p95 17.35 мс, GPU 17.29 мс. По одному проезду на состояние. [Параметры и проверенный источник](parameters.json). Выбор Антона открыт.
