# Десять положений солнца на Small

На обоих направлениях песок остаётся тёплым, металлические панели потеряли сплошной оранжевый оттенок старого контроля. В правой колонке борт ловит более широкий блик, тень от поезда видна справа. В левой колонке свет скользит вдоль панелей. Для выбора достаточно номера от 01 до 10.


Один запуск Unreal DX11, один ракурс Mammoth, одна фаза облаков и пыли. 50 500 лк и экспозиция 2.3. Углы — фактические значения компонента направленного света Unreal. Высоты растут сверху вниз. Слева азимут −128,85°, справа −80,85°.
