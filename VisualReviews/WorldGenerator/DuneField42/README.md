# Дюнное поле на Small · №42

На сухом участке изменена геометрия, остальные настройки взяты из Layout A 2.3. Новый профиль компонует 28 элементов в семи группах из проверенного рельефа Dune Field M27.3.2. Размер, направление и высота варьируются по seed 42044. Между группами сохранены открытые участки. [Вид сверху](images/overview.jpg) · [С борта](images/rail.jpg) · [Кадр с Mammoth](images/moving.jpg) · [Синхронный проезд, контроль сверху](drive.mp4).

Изменения занимают 1.02 км² в одном секторе Landscape. Максимальная прибавка высоты 58.9 м. Отсчёты вдоль всех путей, у мокрой зоны и на стыках тайла совпали побитово. Участки солончака за пределами этого сектора не изменялись. Отдельная карта сохраняет 21 путь и пять поездов. Тесты проверяют закреплённые файлы исходного поля, защитные маски и совпадение расчёта частями.

Сверху видны группы коротких гребней и затенённых ложбин по обе стороны кривой, с ровными проходами между группами. Из поезда силуэт среднего плана стал ступенчатым; передний план вдоль рельсов остался открытым. При боковой камере Mammoth закрывает часть нового поля. В этом проезде солончак в кадр не попал; сохранность его высот проверена отдельно по данным.


В игре прежний/новый рельеф в диагностической точке: 15.39/50.75 м. Размер кадра 1440×810, DX11. До/после: 165.1/165.2 м, p95 кадра 17.92/17.94 мс, GPU 22.15/22.73 мс. По одному проезду на состояние. [Параметры и хеши](parameters.json). Выбор Антона открыт.
