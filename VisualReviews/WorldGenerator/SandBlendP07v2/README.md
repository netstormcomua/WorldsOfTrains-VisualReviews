# SandBlend P07 v2 · Small +65 м

Верхняя панель — сохранённый проезд v1. Нижняя — новый проезд v2 при том же солнце, камере и профиле пыли 04.

[Кадр с поезда](moving.jpg) · [Крупный план](sample.jpg) · [Совмещённые проезды](drive.mp4)

В v2 на склоне по-прежнему видны ориентированные по ветру гребни. Они слабее по тону, фактура RockyB лучше проступает между ними. В одинаковом крупном плане среднее абсолютное отличие яркости от исходного RockyB 02 уменьшилось с 22,95 до 11,83 уровня из 255. Параллельный рисунок гребней вблизи сохраняется.

Первые четыре показателя измерены по маске на мировом поле. Остальные получены в игре при DX11/SM5, 1440×810 и лимите 60 fps. У 1152 компонентов подтверждён включённый слой. В каждом проезде по 12 пылевых объёмов, координаты пробника совпали. Ролики совмещены по ближайшему записанному кадру к отметке +65 м. Один исторический и один новый проезд дают ограниченную оценку производительности. Обе версии сохранены для художественного выбора.
