# №67 · Посадка камней RockyStone41 у Small

Верх — исходная посадка, низ — кандидат. На паре из одного сеанса нижняя полка главного камня уходит в песок, пропадает узкая высокая опора. Меньший обломок на переднем плане виден частично, у главного читаются верхние слои и разломы. В боковом движении заметнее всего понижение силуэта главного камня. Мелкие полки на этой дистанции различить трудно.

Для 52 камней опускание только по Z рассчитано по высотам выборки вершин меша относительно местного Landscape. Диапазон 0,076–1,459 м. Сохранены XY, повороты, масштаб, растения и коллизия. У 52 наносов сравнение вершин и индексов совпало, 16 224 треугольника. Минимальное расстояние в плане от оси железнодорожного сплайна до охватывающей окружности камня 29,01 м.

Один боковой DX11-проезд при 10 м/с, 130,05 м против сохранённых 130,07 м. Движение синхронизировано у 30 м. p95 кадра 18,11 → 17,58 мс, GPU p95 22,52 → 21,88 мс; по одному замеру на вариант. Кандидат сохранён отдельно для художественного выбора.
