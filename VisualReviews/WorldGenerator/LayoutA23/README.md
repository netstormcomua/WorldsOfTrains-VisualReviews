# Layout A 2.3 · выбранный игровой песок

Состояние принято Антоном: RockyB 02, тайл 5,35 м, контраст фактуры 1,65×, усиленный антитайлинг АТ+, лёгкая пыль DuneStorm 04. На новой основной карте связка действует сразу при запуске. База — Layout A 2.2; сохранены прежняя версия и отдельная лаборатория.

[Тот же момент с поезда](images/moving.jpg) · [Тот же участок вблизи](images/sample.jpg) · [Полный игровой кадр](images/game.jpg) · [Реальный DX11-проезд](drive.mp4).

В верхней половине пар — прежний контроль RockyB, в нижней — сохранённая связка целевой сцены. Солнце и точка пробника совпали. Игра прочитала сохранённую текстуру и три выбранных параметра на 1152 компонентах Landscape, 12 объёмов пыли, 21 путь и пять поездов. Стенд ничего не подставляет перед проверкой. По Small пройдено 187,2 м, кадр сделан на +65,09 м; при 1440×810 и лимите 60 fps кадр p95 17,81 мс, GPU p95 21,85 мс. Порядок соединений восстановлен и проверен по графу при сохранении. Этот прогон охватывает выбранный эпизод Small; полного повторного обхода всех пяти маршрутов не проводилось. [Измерения и версия](parameters.json).
