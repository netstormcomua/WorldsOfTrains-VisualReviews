# P07 v3 · Small +65 м

При выключенном №12 на крупном плане RockyB 02 отмечены два фрагмента с повторяющейся светлой полосой между гребнями. После согласованного сдвига фаз альбедо, нормалей и шероховатости корреляция этой пары уменьшилась с 0,867 до 0,465. По 252 участкам того же кадра p95 лучших удалённых совпадений изменился лишь с 0,825 до 0,818. Контраст деталей RMS сохранился (8,72 и 8,67). Выбранный мотив ослаб на прежнем месте, похожие полосы в остальном кадре сохраняются.

[Чистый 02 вблизи, отмеченные участки](02-close.jpg) · [Чистый 02 с поезда](02-ride.jpg)

В конечной смеси примесь №12 чаще, но слабее. На участке маски 1200×960 м покрытие v2/v3 составляет 23,09%/26,20%, средний вес внутри пятна 0,250/0,107, максимум 0,42/0,18. В совмещённом отрывке v3 гребни не образуют столь заметных повторяющихся пятен перед поездом. В крупном плане направленные ряды ещё читаются. Вывод относится к проверенному участку Small.
