# SandBlend P07 · песок с поезда на Small +65 м

Сверху контроль A (RockyB 02 из Layout A 2.3), снизу B (тот же песок с отдельными пятнами MegaRipples 12). Тайл RockyB 5,35 м, контраст 1,65×, усиленный антитайлинг, пыль 04. На этой камере справа и перед поездом видны отдельные пятна. Переход к RockyB плавный. Внутри пятен гребни образуют хорошо различимые параллельные ряды с регулярным шагом. Особенно заметно вблизи. Кандидат остаётся в тестовой карте.

[Вид из движущегося поезда](moving.jpg) · [Ближняя камера](sample.jpg) · [Синхронный отрывок проезда](drive.mp4)

DX11/SM5, 1440×810, 100%, лимит 60 fps. По одному проезду в каждом состоянии. На 1152 компонентах прочитан фактический переключатель. Совпали солнце, координаты ближней пробы и 12 пылевых объёмов. Кадры в движении сняты на +65,079 и +65,091 м. Видео совмещено по ближайшему записанному кадру к каждой отметке +65 м. Один кадр записи соответствует примерно 0,37 м хода.

| Показатель | A | B |
|---|---:|---:|
| Дистанция, м | 187,21 | 187,13 |
| Кадр p95, мс | 18,21 | 18,27 |
| GPU p95, мс | 22,95 | 23,02 |
| Частота захвата, кадров/с | 28,06 | 28,61 |

Разница p95 кадра составила 0,06 мс, GPU — 0,08 мс по неокруглённым значениям. Одна пара ограничивает точность оценки стоимости. Художественный выбор остаётся открытым.
